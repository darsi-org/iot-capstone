# Wokwi path (no hardware)

1. Open https://wokwi.com and sign in free.
2. Create an ESP32 + DHT22 project, paste `device/main.py`.
3. Change the simulated temperature to capture variety.
4. Copy ~180 JSON lines into `data/readings.jsonl`.

Hardware is optional. Wokwi is first-class for this capstone.
